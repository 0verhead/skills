# Planning

For a question too large for one answer that changes the spec or the tickets. The sessions it touches are on hold.

1. Call the Skill tool twice, for `grilling` and `domain-modeling`, so that the ADRs and the glossary keep up with the decisions.
2. Ask the user to run `/to-spec` and `/to-tickets`, so that the spec and the tickets carry the outcome.
3. Have a subagent with a fresh context window check the spec, the tickets and the docs against the decisions, and fix what it finds.
4. Let the held sessions continue.
